UrlFetch.fetch() — one helper for any URL a user or a config field chose

Don't use Node fetch() for untrusted hosts. This helper checks the scheme, rejects credentials in the URL, resolves DNS, refuses private addresses, re-validates every redirect hop, and caps encoded and decoded bytes. Callers can only narrow the site ceiling in utils.urlFetch.

Docs: URL Fetch. The API on this page is admin-only and rate-limited so the site is not an open proxy.
